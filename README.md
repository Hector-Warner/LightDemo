# Light Demo
- This is currently a prototype version of a Roguelike game I'm working on
- The premise of this game is that your health is visually represented by the light your character emits, when you take damage, you produce less light.
- Certain abilities will use light to power them which means you need to be careful with using up your light.
- You can make powerful moves, however you might not be able to see very well afterwards so make sure you are prepared to be fighting in the dark
- You will be able to recharge your light by pulling from torches that you will find around the generated map.

# Controls
- WASD - Movement
- Left Click - Melee attack
- Right Click - Projectile Attack
- Q - Absorb light when near a torch
